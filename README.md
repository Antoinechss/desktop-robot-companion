# Desktop Robot Companion 🤖

My very first hardware project! 

### Motivations for this project 

**If you write code for a living, try building something you can touch!**

In an era where most code is generated by AI, I wanted to start from scratch again and remember what it feels like to make something tangible with my own hands. The idea was simple: a small robot that sits on the counter, notices people in front of it, reacts to sounds, tracks faces and interacts as naturally as possible. Getting there was less simple. Following a face without shaking meant learning control loops. Turning toward a noise meant measuring how much later a sound reaches one microphone than the other. Running two motors, a speaker and a screen off one battery without the Pi rebooting was a project of its own.

It was slow and often frustrating, but I learned a lot along the way. Below, I document the whole process.

### The hardware list 🛒

OK, time to take out the credit card and cross the city to one of the last surviving electronics shops (yes, they still exist, and believe me, there was a one-hour queue to get the components).
